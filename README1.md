В данном отчёте представлены алгоритмы выполнения, использованные команды и результаты практических кейсов по настройке CI/CD пайплайнов.

## Кейс 1: Настройка простого пайплайна CI с использованием GitHub Actions

### Алгоритм выполнения:
1. Создание локальной структуры проекта и инициализация репозитория через `git init`.
2. Создание каталога конфигурации `.github/workflows/` и файла `ci.yml`.
3. Настройка базового сценария автоматической сборки при событии `push`.
4. Фиксация изменений и публикация репозитория на GitHub.  

![Запущенный процесс](/all-ci-cd-cases/images/1.1.PNG)
### Команды:
```bash
git init
mkdir -p .github/workflows
# Создание файла .github/workflows/ci.yml
git add .
git commit -m "Add GitHub Actions CI pipeline"
git branch -M main
git remote add origin <URL-репозитория>
git push -u origin main  
```

## Кейс 6: Настройка уведомлений о статусе пайплайна/

### 1. Описание проделанной работы (Алгоритм):
1. **Настройка SMTP-доступа:** В параметрах безопасности почтового сервиса Mail.ru (`id.mail.ru`) сгенерирован специальный пароль для внешних приложений для безопасного подключения сторонних сервисов по протоколу SMTP.
2. **Конфигурация секретов GitHub:** В настройках репозитория (`Settings -> Secrets and variables -> Actions`) созданы защищенные переменные окружения:
   * `MAIL_USERNAME` — электронная почта отправителя (`artemeva.anastasya@inbox.ru`).
   * `MAIL_PASSWORD` — сгенерированный 16-значный пароль приложения.
3. **Модификация воркфлоу GitHub Actions:** В файл `.github/workflows/ci.yml` добавлен финальный шаг `Send Email Notification` с использованием экшена `dawidd6/action-send-mail@v3`.
4. **Настройка выравнивания YAML:** Исправлена структура отступов в `ci.yml` (выравнивание блоков `steps` и `with`), что устранило синтаксическую ошибку `Invalid workflow file`.
5. **Гарантия выполнения:** Для шага отправки почты задано условие `if: always()`, обеспечивающее отправку уведомления о статусе сборки (`${{ job.status }}`) как при успешном выполнении, так и при сбоях.

### 2. Использованные команды:
```bash
# Проверка статуса измененных файлов
git status

# Добавление конфигурации воркфлоу и отчета в индекс
git add .github/workflows/ci.yml README.md

# Фиксация изменений
git commit -m "Case 6: Fix YAML syntax and configure Mail.ru SMTP notifications"
git push origin main
```
## Кейс 6: Настройка автоматических уведомлений по почте (Pipeline Notifications)

### 1. Описание проделанной работы:
1. **Генерация пароля приложения:** В сервисе Mail.ru (`id.mail.ru` -> раздел «Безопасность» -> «Пароли для внешних приложений») создан специальный 16-значный пароль для внешних приложений для безопасной аутентификации по SMTP.
2. **Конфигурация секретов в GitHub:** В настройках репозитория (`Settings -> Secrets and variables -> Actions`) добавлены переменные окружения:
   * `MAIL_USERNAME` — электронная почта отправителя (`artemeva.anastasya@inbox.ru`).
   * `MAIL_PASSWORD` — сгенерированный пароль приложения Mail.ru.
3. **Добавление шага отправки в воркфлоу:** В файл `.github/workflows/ci.yml` интегрирован экшен `dawidd6/action-send-mail@v3` с использованием SSL-порта 465 и SMTP-сервера `smtp.mail.ru`.
4. **Гарантированное выполнение:** Добавлено условие `if: always()`, чтобы статус сборки (`${{ job.status }}`) отправлялся на почту независимо от успешности предшествующих шагов пайплайна.

### 2. Использованные команды:
```bash
# Проверка измененных файлов
git status

# Индексация обновленного файла конфигурации
git add .github/workflows/ci.yml

# Фиксация и отправка изменений на GitHub
git commit -m "Case 6: Add email notification via Mail.ru SMTP"
git push origin main
```
