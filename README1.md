# Отчёт по практической работе: CI/CD и автоматизация разработки

В данном отчёте представлены алгоритмы выполнения, использованные команды и результаты практических кейсов по настройке CI/CD пайплайнов.

## Кейс 1: Настройка простого пайплайна CI с использованием GitHub Actions

### Алгоритм выполнения:
1. Создание локальной структуры проекта и инициализация репозитория через `git init`.
2. Создание каталога конфигурации `.github/workflows/` и файла `ci.yml`.
3. Настройка базового сценария автоматической сборки при событии `push`.
4. Фиксация изменений и публикация репозитория на GitHub.  

![Запущенный процесс](/all-ci-cd-cases/images/1.1.PNG)
### Команды:
```bash
git init
mkdir -p .github/workflows
# Создание файла .github/workflows/ci.yml
git add .
git commit -m "Add GitHub Actions CI pipeline"
git branch -M main
git remote add origin <URL-репозитория>
git push -u origin main  
```

* В файле прописаны основные этапы работы пайплайна (stages): `build` (сборка проекта) и `test` (автоматическое тестирование).

## Кейс 3: Автоматическое развертывание на Heroku с использованием CircleCI

### 1. Описание проделанной работы (Алгоритм):
* В корневой директории репозитория создана служебная директория `.circleci` и конфигурационный файл `config.yml`.
* Описан пайплайн для автоматической сборки проекта и развертывания (деплоя) на платформу Heroku.
* Настроены триггеры запуска пайплайна строго при отправке (`push`) изменений в основную ветку `main`.
* В конфигурации определен базовый образ `cimg/node:18.0` для выполнения шагов сборки и деплоя.

### 2. Использованные команды:
```bash
# Создание директории для конфигурации CircleCI и самого файла config.yml
mkdir .circleci
touch .circleci/config.yml

# Добавление файлов в систему контроля версий, коммит и отправка на GitHub
git add .circleci/config.yml README.md
git commit -m "Case 3: Add CircleCI config for Heroku deployment"
git push origin main 
``` 
## Кейс 4: Использование Docker в пайплайне CI/CD

### 1. Описание проделанной работы (Алгоритм):
* В корневой директории репозитория создан **`Dockerfile`** для контейнеризации приложения на базе Node.js.

* В сценарий автоматизации добавлена логика авторизации в реестре контейнеров Docker Hub, сборки тегированного Docker-образа и его отправки (`docker push`).
* Определены шаги для безопасной работы с учетными данными через переменные окружения.

### 2. Использованные команды:
```bash
# Создание Dockerfile в корне проекта
